# Админские команды SafeOut

Работают только если твой Telegram ID прописан в `ADMIN_ID` на Railway.
Узнать свой ID: написать @userinfobot.
Прописать: `railway variables --set "ADMIN_ID=ТВО_ID" --service bot`

---

## В боте (прямо в чате)

| Команда | Что делает |
|---|---|
| `/ping_now` | Прислать проверочный пинг прямо сейчас (не ждать 15 минут) — для тестирования |
| `/stats` | Показать статистику: сколько пользователей, свиданий, активных сессий, SOS |
| `/tubiki` | Коллекция тюбиков с датами свиданий |
| `/gift <user_id>` | Выдать Premium пользователю (бесплатный безлимитный доступ) |
| `/revoke <user_id>` | Отозвать Premium у пользователя |
| `/users` | Список всех пользователей и их статус (Premium / кол-во использованных свиданий) |

**Узнать user_id нужного человека:** попроси их написать @userinfobot — он пришлёт их ID.

---

## В терминале (Railway CLI)

**Посмотреть логи бота:**
```bash
railway logs --service bot
```

**Посмотреть логи воркера (Celery — задачи пингов и эскалаций):**
```bash
railway logs --service worker
```
В логах воркера видно каждый запуск пинга: `ping_user: session=X telegram_id=Y attempt=0`
Если задача падает — там же будет полный traceback.

**Перезапустить сервис (если завис):**
```bash
railway up --service bot --detach
railway up --service worker --detach
```

## Как тестировать флоу пингов

1. Запустить `/newdate` → заполнить данные
2. Отправить `/ping_now` → должен прийти пинг с тремя кнопками
3. Нажать «✅ Всё хорошо» → бот подтвердит, следующий пинг запланирован на +15 мин
4. Снова `/ping_now` → следующий пинг
5. Не нажимать ничего → через 15 минут должно прийти уведомление «я написала контактам»

---

## Как тестировать эскалацию

1. Запустить свидание → `/ping_now`
2. **Не нажимать кнопки** → подождать 15 минут
3. Контакты получат уведомление, тебе придёт «я уже написала твоим контактам»
4. Кнопка «✅ Всё хорошо» возобновит пинги
